# NAAIL Research Note — AI Benchmarking Reference

**Research portfolio curator:** Dr. Saeid Homayoun  
**ORCID:** https://orcid.org/0000-0002-2536-0446

This repository is treated within NAAIL as a **supporting AI-model benchmarking/reference resource**, not as evidence that the underlying Artificial Analysis benchmarks or upstream material were created by NAAIL.

The repository's existing GPL terms and all third-party data/image/source rights remain controlling. This note does not add a non-commercial restriction to GPL-covered material and does not claim ownership of third-party benchmark content.

For original NAAIL model-selection studies, use frozen evaluation criteria, version/date stamps, provenance, independent benchmarks, sensitivity analysis, cost/latency/quality trade-offs, adversarial evaluation, and human approval. Do not select models solely because they improve a preferred empirical result.

Scientific workflow:

**Question → benchmark provenance → competing model hypotheses → ERA evaluation object → AlphaEvolve-style controlled comparison → robustness/OOS tests → AI-to-AI review → Chain-of-Evidence → Human Gate.**

Any patent-sensitive original NAAIL evaluation or routing mechanism should remain private until IP review. Public GitHub publication is not a patent filing.
